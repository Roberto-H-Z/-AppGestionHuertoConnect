📁 UI - Componentes de Interfaz
================================
Componentes UI reutilizables y atómicos.

Ejemplos:
- Button.tsx      → Botones con variantes (primary, secondary, outline)
- Input.tsx       → Campos de texto con validación
- Card.tsx        → Tarjetas contenedoras
- Badge.tsx       → Badges/etiquetas
- Modal.tsx       → Modales reutilizables
- Loader.tsx      → Indicadores de carga
- Avatar.tsx      → Avatares de usuario
