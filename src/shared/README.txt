📁 SHARED - Recursos Compartidos
=================================
Componentes, hooks y utilidades reutilizables en toda la app.

- components/ui/      → Componentes UI básicos (Button, Input, Card)
- components/layout/  → Componentes de layout (Header, Footer, Container)
- hooks/              → Custom hooks globales (useDebounce, useAsync)
- utils/              → Funciones utilitarias (formatDate, validators)
- constants/          → Constantes (API_URL, COLORS, SIZES)
- types/              → TypeScript types globales
