📁 USE-CASES - Casos de Uso
===========================
Contiene la lógica de aplicación (orquestación de entidades).

Cada caso de uso representa una acción que el usuario puede realizar.

Ejemplo:
- CreateGarden.ts         → Crear un nuevo huerto
- AddPlantToGarden.ts     → Agregar planta a huerto
- GetGardenStatus.ts      → Obtener estado del huerto
- AskAIAssistant.ts       → Consultar al asistente IA
- GetWeatherForecast.ts   → Obtener pronóstico del clima
