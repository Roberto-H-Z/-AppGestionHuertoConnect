📁 DOMAIN - Modelo de Dominio
=============================
Define las entidades y reglas de negocio puras.

- entities/       → Clases/interfaces de entidades (Huerto, Planta, Usuario)
- value-objects/  → Objetos de valor inmutables (Coordenadas, Temperatura)

Ejemplo:
- entities/Garden.ts      → Entidad Huerto
- entities/Plant.ts       → Entidad Planta
- value-objects/Location.ts
