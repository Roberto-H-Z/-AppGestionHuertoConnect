📁 AI-ASSISTANT - Asistente IA
===============================
Módulo del asistente inteligente con IA.

- screens/    → ChatScreen, RecommendationsScreen
- components/ → ChatBubble, MessageInput, SuggestionChips
- hooks/      → useAIChat, useRecommendations
- services/   → aiService.ts (comunicación con OpenAI/modelos)

Funcionalidades:
- Chat conversacional para preguntas sobre huertos
- Diagnóstico de plantas por imagen (Cloudinary + IA)
- Recomendaciones de cuidado basadas en clima
