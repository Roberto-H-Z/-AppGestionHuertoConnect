📁 FEATURES - Módulos por Funcionalidad
========================================
Cada feature es un módulo independiente de la app.

- auth/         → Autenticación (login, registro, recuperar contraseña)
- gardens/      → Gestión de huertos (CRUD, listados, detalles)
- plants/       → Gestión de plantas (CRUD, información, cuidados)
- monitoring/   → Monitoreo (sensores, alertas, estadísticas)
- ai-assistant/ → Asistente IA (chat, recomendaciones, diagnóstico)

Cada feature contiene:
- screens/     → Pantallas de la funcionalidad
- components/  → Componentes específicos del feature
- hooks/       → Custom hooks del feature
- services/    → Lógica de negocio específica
