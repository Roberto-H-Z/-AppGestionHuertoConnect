📁 EXTERNAL-SERVICES - APIs Externas
=====================================
Clientes para servicios de terceros.

- weather/     → API del clima (OpenWeatherMap, WeatherAPI, etc.)
- ai/          → Servicios de IA (OpenAI, modelos free, etc.)
- cloudinary/  → Gestión de imágenes (subir, transformar)

Cada carpeta contiene:
- client.ts    → Configuración del cliente
- types.ts     → Tipos de respuesta
- service.ts   → Funciones de acceso
