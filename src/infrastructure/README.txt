📁 INFRASTRUCTURE - Adaptadores Externos
=========================================
Implementa las conexiones con el mundo exterior.

- api/               → Cliente HTTP para tu microservicio Node.js
- external-services/ → APIs externas (clima, OpenAI, Cloudinary)
- storage/           → Persistencia local (AsyncStorage, SQLite)
- repositories/      → Implementación de los puertos de salida
